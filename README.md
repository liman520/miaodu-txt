# miaodu-txt

秒读系列项目合集（Monorepo）

## 📁 项目列表

| 项目 | 说明 | 技术栈 |
|------|------|--------|
| [miaodu-publisher](./miaodu-publisher/) | AI 全自动文章采集发布系统 | FastAPI + SQLite + Playwright |

## 🚀 快速开始

进入对应项目目录，按各项目 README 进行安装和运行。

```bash
# 示例：运行 miaodu-publisher
cd miaodu-publisher
pip install -r requirements.txt
python -m app.main
```

## 📌 说明

本仓库采用 monorepo 结构，每个项目独立存放在各自的子目录中，互不干扰。

后续项目（小程序、新版网页端等）会陆续添加到本仓库中。
